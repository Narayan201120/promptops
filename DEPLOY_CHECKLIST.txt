PromptOps Deployment Checklist
================================

PRE-DEPLOYMENT
□ All features tested locally
□ Environment variables documented
□ API keys ready (OpenAI, Anthropic)
□ GitHub account ready
□ Railway account created
□ Vercel account created

STEP 1: GITHUB (5 min)
□ git init
□ git add .
□ git commit -m "Ready for deployment"
□ Create GitHub repo
□ git remote add origin <url>
□ git push -u origin main

STEP 2: RAILWAY BACKEND (10 min)
□ Create new project from GitHub
□ Add PostgreSQL database
□ Add Redis database
□ Set environment variables:
  □ SECRET_KEY
  □ DEBUG=False
  □ ALLOWED_HOSTS
  □ DATABASE_URL (auto)
  □ REDIS_URL (auto)
  □ OPENAI_API_KEY
  □ ANTHROPIC_API_KEY
  □ CORS_ALLOWED_ORIGINS
□ Add Celery worker service
□ Run: python manage.py migrate
□ Run: python manage.py create_test_data
□ Copy Railway URL

STEP 3: VERCEL FRONTEND (5 min)
□ Import GitHub repo
□ Set root directory: frontend
□ Add environment variable:
  □ VITE_API_URL=<railway-url>/api
□ Deploy
□ Copy Vercel URL

STEP 4: UPDATE CORS (2 min)
□ Update CORS_ALLOWED_ORIGINS in Railway
□ Redeploy Django service

STEP 5: TEST (5 min)
□ Visit Vercel URL
□ Register account
□ Create prompt
□ Test prompt
□ View analytics
□ Check all features work

POST-DEPLOYMENT
□ Monitor Railway logs
□ Monitor Vercel logs
□ Set up error tracking (optional)
□ Configure custom domain (optional)
□ Share with users!
